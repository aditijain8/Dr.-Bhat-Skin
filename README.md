# Dr. Bhat Skin Clinic Website

A responsive, single-page website for a dermatology clinic in Jakkasandra, Bengaluru, with services, clinic timings, location map and an appointment request form.

**Live site:** https://dr-bhat-skin.vercel.app

## Features

- Hero section with call-to-action and click-to-call button
- About, services, healthcare packages and areas-served sections
- Weekly clinic timings with open/closed days
- Embedded Google Map and address
- Appointment request form
- Mobile-friendly navigation and layout

## Tech stack

HTML5, CSS3 and vanilla JavaScript, with Google Fonts (Inter and Playfair Display). Deployed on Vercel.

## Project structure

```text
.
├── index.html   # page markup
├── style.css    # styling
├── script.js    # navigation and form behaviour

```
